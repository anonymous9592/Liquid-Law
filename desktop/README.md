# Case Canvas desktop (Electron)

Windows shell for the Case Canvas renderer in `../prototype/`. The renderer is served through a privileged
`app://index/` scheme (dev: `../prototype`; packaged: `resources/prototype` via `extraResources`).

## Run in dev
```
cd desktop
npm install
npm start
```
Dev mode logs `did-finish-load` and renderer console messages to stdout.

## Build (Windows)
```
npm run build:win
```
Output in `desktop/dist/`: `Case Canvas Setup <version>.exe` (NSIS installer) and `Case Canvas <version>.exe`
(portable). `.lawcase` is registered as a file association by the installer. Icon is generated by
`node build/make-icon.js` (output `build/icon.ico`, already committed to the folder).

## Bridge contract (`window.desktop`, see docs/SPEC-case-file.md section 6)
- `isDesktop: true`, `version`
- `openCase(): Promise<{path,name,bytes:Uint8Array} | null>`
- `saveCase(bytes, path|null, suggestedName): Promise<{path,name} | null>` (null path shows Save As)
- `openPdfs(): Promise<{name,bytes}[]>`
- `setTitle(title)`
- `onMenu(cb)` with `'new'|'open'|'save'|'saveAs'|'openPdf'`
- `onOpenFile(cb)` receives `{path,name,bytes}` for double-clicked / "Open with" / second-instance `.lawcase` files
  (delivered after the renderer finishes loading, so register callbacks synchronously at startup).
